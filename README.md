# Rinstudio. Видео-сервис

Учебный проект в рамках 5-го спринта. 
Представляет собой аналог VK Video, есть возможности просмотра, загрузки и авторизации.

## Функционал

- **Лента видео**: динамическая загрузка данных, адаптивная сетка, анимированные скелетоны при загрузке.
- **Просмотр видео**: модалка окно с HTML5-плеером, лоадер до загрузки, автоматическое увеличение счетчика просмотров (+1).
- **Загрузка видео**: 3-шаговый процесс (загрузка превью -> загрузка видео -> создание записи). Валидация файлов по типу и размеру.
- **Авторизация**: регистрация и вход, сохранение JWT-токена, защита роутов.
- **Динамическая валидация**: форма загрузки валидируется на лету через Zod (подсветка ошибок, блокировка кнопки).
- **Фича "Поделиться"**: копирование ссылки на конкретное видео с возможностью открытия по прямой ссылке (query-параметр `?video=ID`).
- **Котик Oneko**: фишка с 4 спринта (пусть будет)
- **Нативный api-клиент**: собственный api-клиент на фетчах

## Архитектура (FSD)

Проект разбит на слои согласно методологии Feature-Sliced Design:

- `app/` - инициализация приложения, роутинг, глобальные лейауты.
- `pages/` - страницы (Лента, Авторизация).
- `widgets/` - самостоятельные UI-блоки (Сайдбар, Список видео, Модалки).
- `features/` - пользовательские сценарии (Авторизация, Загрузка видео).
- `entities/` - бизнес-сущности (Video, User, Session).
- `shared/` - переиспользуемый код (API-клиент, конфиг, утилиты).

## Зависимости

Установите Node.js, если у вас он не установлен

## Установка и запуск

```bash
# 1. Клонировать нужную ветку
git clone -b sprint5 https://github.com/rindouwu/sprints.git
cd sprints

# 2. Установить зависимости
npm install

# 3. Создайте .env на основе .env.example
# при желании смените VITE_API_URL на свой
cp .env.example .env

# 4. Запустить dev-сервер
npm run dev
```

После запуска откройте http://localhost:5173
